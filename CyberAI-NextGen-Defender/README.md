# 🧠 CyberAI NextGen Defender

## Overview
AI-driven cybersecurity platform for detecting phishing, spam, malware, DDoS, and IoT threats. Includes a Streamlit dashboard and trained models.

## Structure
- data/                 # datasets (samples)
- notebooks/            # Jupyter notebooks for experiments
- models/               # saved models
- app/                  # Streamlit app
- requirements.txt
- README.md

## Quick start
1. Install dependencies:
   pip install -r requirements.txt
2. Open notebooks/ and run cells to train models.
3. Launch the dashboard:
   streamlit run app/streamlit_app.py
